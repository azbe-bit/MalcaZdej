# MalcaZdej

## 1. Ime in namen aplikacije
**MalcaZdej** je preprosta spletna aplikacija v Djangou, namenjena pregledu dnevne ponudbe šolskih malic ter enostavnemu naročanju in upravljanju ponudbe za dijake in osebje.

## 2. Člani ekipe in prispevki
* **Ime Člana 1** – Postavitev projekta, podatkovni model (`models.py`), administracija.
* **Ime Člana 2** – Pogledi (`views.py`), URL-ji in HTML predstavitvene predloge.
* **Ime Člana 3** – Git upravljanje, testiranje delovanja in odpravljanje napak.
